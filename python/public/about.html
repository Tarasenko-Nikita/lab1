Моя реалізація

Спочатку ми отримуємо чистий шлях запиту та порівнюємо отриманий результат з відомими маршрутами. Залежно від збігу формується шлях до потрібного файлу. Файл зчитується. Якщо файл знайдено, то сервер надсилає у відповідь статус 200, у іншому ж випадку - 404.
